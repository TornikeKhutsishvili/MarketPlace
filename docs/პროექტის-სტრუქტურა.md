# პროექტის სტრუქტურა

MarketPlace — ონლაინ მარკეტპლეისის ფრონტენდ-პროექტი (HTML5 · CSS3 · Vanilla JS)

## მთავარი საქაღალდეები

| საქაღალდე | დანიშნულება |
| --- | --- |
| `css/` | სტილები: დიზაინ-ტოკენები, კომპონენტები, რესპონსივი |
| `js/` | JavaScript მოდულები (თითო გვერდზე თითო ლოგიკა + საერთო ფაილები) |
| `images/` | გამოსახულებები (favicon) |
| `docs/` | პროექტის სტრუქტურა, საბოლოო ანგარიში, პრეზენტაცია |

## HTML გვერდები (root)

| ფაილი | დანიშნულება |
| --- | --- |
| `index.html` | მთავარი გვერდი: სლაიდერი, კატეგორიები, პოპულარული პროდუქტები, უპირატესობები |
| `catalog.html` | კატალოგი: ძიება, ფილტრები, დალაგება |
| `product.html` | პროდუქტის დეტალური გვერდი (`?id=`) და მსგავსი პროდუქტები |
| `cart.html` | კალათა, პრომო კოდი, შეკვეთის შეჯამება |
| `account.html` | შესვლა / რეგისტრაცია (ტაბები + ვალიდაცია) |
| `contact.html` | კონტაქტის ფორმა |

## css/

| ფაილი | დანიშნულება |
| --- | --- |
| `style.css` | ერთადერთი სტილის ფაილი: `:root` ცვლადები, reset, header/nav, slider, ბარათები, ფორმები, კალათა, footer, media queries |

## js/

| ფაილი | დანიშნულება |
| --- | --- |
| `data.js` | კატეგორიები და 17 დემო-პროდუქტი (mock backend) |
| `main.js` | საერთო: კალათის store (`localStorage`), ბარათის რენდერი, toast, მობილური მენიუ, ფასის ფორმატი, XSS escape |
| `slider.js` | სლაიდერი: ავტო-თამაში, ისრები, წერტილები, swipe, კლავიატურა, პაუზა hover-ზე |
| `home.js` | მთავარი გვერდის კატეგორიები და პოპულარული პროდუქტები |
| `catalog.js` | ძიება, ფილტრები, დალაგება, URL პარამეტრები |
| `product.js` | პროდუქტის გვერდის რენდერი, რაოდენობა, მსგავსი პროდუქტები |
| `cart.js` | კალათის გვერდი: რაოდენობა, წაშლა, პრომო, ჯამები, checkout |
| `forms.js` | ფორმების ვალიდაცია და შესვლა/რეგისტრაციის ტაბები |

## ძირითადი ფაილები

| ფაილი | დანიშნულება |
| --- | --- |
| `README.md` | პროექტის დოკუმენტაცია |
| `.gitignore` | Git-ის მიერ იგნორირებული ფაილები |
| `images/favicon.svg` | საიტის ხატულა |

## ფაილებს შორის კავშირი

```
HTML გვერდი ──> css/style.css
            ──> js/data.js ──> js/main.js ──> გვერდის სკრიპტი (home | catalog | product | cart | forms)
```

`data.js` და `main.js` ყველა გვერდზე იტვირთება; გვერდის სკრიპტი მხოლოდ თავის გვერდზე.
