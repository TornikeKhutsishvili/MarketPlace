# 🛒 MarketPlace

ონლაინ მარკეტპლეისის ფრონტენდ-პროექტი — სასწავლო საფინალო პრაქტიკული პროექტი (Skillwill, ფრონტენდ პროგრამირება).

## 🧰 ტექნოლოგიები და არჩევის მიზეზი

- **HTML5** — სემანტიკური ტეგები (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- **CSS3** — CSS Variables, Grid (პროდუქტების ბადე, layout), Flexbox (ნავიგაცია, ბარათები), `clamp()`, media queries.
- **JavaScript (ES2020)** — DOM, Event Delegation, `localStorage`, `URLSearchParams`.
- **Git/GitHub** — Conventional Commits.
- **VS Code, Chrome DevTools, Lighthouse** — დეველოპმენტი და აუდიტი.

ფრეიმვორკი შეგნებულად არ გამოვიყენე: შეფასების მიზანია ვებ-ფუნდამენტების ცოდნა, ხოლო პროექტი მცირეა და ბილდ-ინსტრუმენტები ზედმეტი იქნებოდა.

## ⚡ ოპტიმიზაცია

**Lighthouse (ცოცხალი საიტი, მობილური):** Accessibility 100, Best Practices 100, SEO 100, Performance 84–93. HTML ვალიდაცია (html-validate) — შეცდომების გარეშე.

- ერთი CSS ფაილი, ერთი HTTP მოთხოვნა სტილებზე; გამოუყენებელი კოდის გარეშე.
- სკრიპტები `defer`-ით — რენდერს არ ბლოკავს, თითოეულ გვერდზე მხოლოდ საჭირო მოდულები იტვირთება.
- გარე სურათები/შრიფტები/ბიბლიოთეკები არ გამოიყენება (emoji + CSS გრადიენტები, system font stack) → ნულოვანი გარე დამოკიდებულება.
- ბარათების გენერაცია ერთი `innerHTML` ოპერაციით (მინიმალური DOM reflow).
- Event Delegation — ერთი listener ყველა „კალათაში დამატების“ ღილაკზე.
- XSS-დაცვა: დინამიკური ტექსტი გადის `MP.escape()`-ში.
- უსაფრთხო `localStorage` წაკითხვა (`try/catch`, ტიპის შემოწმება).
